# Native AR floor survey — opt-in device measurement candidate

Android only; no public website/company platform changes. ARCore 1.54.0 is configured as optional so unsupported devices keep all existing non-AR paths. See Google's AR Optional and privacy requirements (https://developers.google.com/ar/develop/java/enable-arcore and https://developers.google.com/ar/develop/privacy-requirements). A private internal activity asks for consent and camera access, checks runtime availability and installation, then opens a local ARCore session using a live OES texture. There is no Cloud Anchor, Geospatial, video recording, photo upload or reconstructed mesh. Four user-marked, tracked anchors on the same upward-facing horizontal plane must form a plausible rectangle. Planarity, corner closure, opposing sides and right-angle checks reject internally inconsistent marks; thresholds are not an independent accuracy claim. The scene and anchors are transient. The returned dimensions are an explicit draft candidate. Existing plant/window coordinate frames are never silently transformed. An authorized owner or manager may use a checked result for an empty layout and must still use the existing room save and revision checks. Manual recording always remains available.

Requires exact-head build, physical supported handset session, actual floor targets and comparison against tape-measured dimensions across rooms and repeats. A package being installed does not establish working tracking or accuracy. No production flag change, migration, deployment or publication.
