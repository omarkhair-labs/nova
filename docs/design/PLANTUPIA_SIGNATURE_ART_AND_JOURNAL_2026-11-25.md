# Plantupia — native art and journal extension
Draft, not production-approved. Built on the same signature implementation branch.
- Port five original Study 02 navigation glyphs to Android vectors and adapt nine Study 04 field-plate compositions into native drawable resources. Grain, microtype and some decorative marks deliberately omitted for small-screen readability; no supplied plant or commercial photos replaced. Plates are conceptual topic illustrations, not prescriptions.
- Welcome threshold: compact botanical/architectural drawing, reduced vertical gaps, same authenticated entry and QR/legal routes.
- One coherent bottom bar, selected state and 48dp minimum navigation targets. Retain route identities and screen-reader labels; no extra roots.
- Private journal: search loaded records and linked outcomes; explicitly select two real loaded photos on distinct dates. Never infer growth or accept an unloaded/same photo.
- Guide: current chapter number, next/previous from only published topics; no care writes.
- Ask: account-keyed context, optional search for larger loaded collections and retry when plants unavailable; no automatic context consent.
- Today: dark editorial personal-check stage using actual date/name/photo; Create: private/public intention; Profile: adaptive stats for larger text.
- Added JVM tests for journal filtering and explicit photo-pair validation.
Full exact-head Android build, instrumented test execution, screenshot/RTL/large-text/accessibility and live QA remain mandatory. No app deployment, new paid feature, backend or private customer data.
