# Linux ARM64 vision candidate

Do not enable the new build flag on a running preview before native ARM preflight passes. The ordinary QA image remains unchanged with this flag off. MediaPipe 0.10.18 provides a CPython 3.12 Linux ARM wheel and preserves the previously used ROI/float-confidence interface; pin the NumPy/protobuf/JAX dependencies and check their compatibility with the actual backend image. MediaPipe 1.x switched to a different strokes API, so merely replacing the package would not establish compatibility with the reviewed MagicTouch model. The CLI path uses Debian's native CPU COLMAP, parses the registered TXT model, verifies tracks and pose associations, and uses the existing scene export, stereo and photo surface geometry. A bounded native ARM CI job builds the opt-in image, tries real model polygons and reconstruction from eight public overlapping PAA cabbage photos pinned to a dataset commit. This is a compatibility smoke, not validation of health, indoor species, surface completeness or field precision. No new Oracle resources, production database access or user photos. Keep the flag off until exact-head results and server resource checks are reviewed.
