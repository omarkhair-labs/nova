The 26cb61a422fd678634851686e92a41378f5a81ca snapshot retains the previous work in Git history. Basic CameraX photo capture and gallery selection remain, without image-analysis use case or framing overlay; ordinary event cards, recorded photos, manual species selection, reviewed guide, care records, customer spaces, shop, community, existing assistant/support and account boundaries remain. The AR survey activity is not registered; live lens build flag is false for all builds. Old experimental modules, SDK dependencies and backend data are retained for history/engineering recovery, not exposed as customer routes. No backend/Oracle migration, data deletion, production deployment, or Play release. Old preview backend may still advertise capabilities; customer routes must not use them. Tests replace the retired room journey with evidence of ordinary navigation and absence of the retired entry points while checking that prior layout data is not deleted. Existing engine tests remain separate and do not indicate that those tools are offered in the product.
