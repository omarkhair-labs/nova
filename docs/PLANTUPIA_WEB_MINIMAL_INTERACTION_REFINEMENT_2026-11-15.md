## Implementation
- A dedicated image-first Spaces gallery with six sector controls immediately above the photograph; next/previous wrap and a visible progress rail; restrained photo transitions. The image carries no dense text blocks. Caption remains explicit about reference imagery, not client work. Optional design prompts are below the photo. Context-specific links carry the selected sector into contact.
- A light, minimal contact workspace replaces the long space dossier. Three real interaction modes: project, care/support and general. Local copy only; no invented sending, no form database, no contact destination assumed. A blocked clipboard offers a selectable message. User explicitly controls copying. Company approval for live intake remains outstanding.
- Get in touch in the global index; preserve the existing /start-a-space URL and avoid a duplicate route.
- Unchanged production alias until intentional review. Existing hero/studio/living systems remain iterative; genuine project archive awaits authorized content.
