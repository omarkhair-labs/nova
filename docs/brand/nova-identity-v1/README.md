# Nova Identity v1

## Thesis

**Nova happens between us.**

The mark is built from two independent, asymmetric forms. Neither form is Nova by itself. The controlled shared void and visual response between them create the identity.

## Palette

- Deep Space `#0A0B14`
- Nova Purple `#7B5CFF`
- Electric Blue `#2D8BFF`
- Sunrise Peach `#FFB8A7`
- Soft Light `#E9E6FF`
- Background `#F8F9FF`

## Motion DNA

`Separate → Approach → Interact → Settle`

## Product integration

Identity v1 is wired into the adaptive launcher icon, themed monochrome icon, notification small icon, Android 12+ system splash, Welcome screen, Home identity header, and the base Nova palette.

## Guardrails

1. Keep the two forms separate; never bridge the void with a stroke.
2. Do not add stars, planets, orbit rings, infinity loops, or a literal `N` inside the mark.
3. At small sizes, prefer the monochrome silhouette.
4. The gradient is a treatment, not the concept.
