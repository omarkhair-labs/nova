# Nova production deployment

Nova's first hosted environment is designed for Railway:

- Django + Gunicorn web service
- Railway PostgreSQL
- Railway S3-compatible Storage Bucket for avatars and post images
- HTTPS public domain generated by Railway

## Railway service layout

Create one Railway project with three resources:

1. A service deployed from the `omarkhair70-droid/nova` GitHub repository.
2. A PostgreSQL database.
3. A Storage Bucket.

For the app service, set the Root Directory to `/backend` so Railway builds `backend/Dockerfile`.

## Required app variables

Set these on the Django app service:

```text
DJANGO_ENV=production
DJANGO_DEBUG=0
DJANGO_SECRET_KEY=<long-random-secret>
DATABASE_URL=${{Postgres.DATABASE_URL}}
DJANGO_ALLOWED_HOSTS=${{RAILWAY_PUBLIC_DOMAIN}}
```

Inject/reference the Storage Bucket credentials into the app service using these names:

```text
AWS_ENDPOINT_URL
AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY
AWS_S3_BUCKET_NAME
AWS_DEFAULT_REGION
AWS_S3_URL_STYLE
```

Railway exposes matching S3-compatible credentials from the bucket Credentials panel.

## Deploy lifecycle

The production Docker image starts by running migrations and static collection, then launches Gunicorn:

```text
python manage.py migrate --noinput
python manage.py collectstatic --noinput
gunicorn nova_backend.wsgi:application
```

After the deployment is active, generate a Railway public domain and verify:

```text
https://<railway-domain>/api/v1/health/
```

Expected response:

```json
{"status":"ok","service":"nova-api"}
```

## Local development stays unchanged

`docker compose up --build` still uses local PostgreSQL and local media files. Production switches to Railway PostgreSQL and the object storage bucket only when `DJANGO_ENV=production` and the production environment variables are present.

## Android handoff

Once Railway generates the final HTTPS domain, update Nova's Android API base URL from the local `127.0.0.1:8000` address to:

```text
https://<railway-domain>/api/v1/
```

After that change, `adb reverse` and a running laptop are no longer required for normal app use.
