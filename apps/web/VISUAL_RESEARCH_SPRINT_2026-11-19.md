# Visual Research Sprint — 2026-11-19

## Why this pass exists
The private review had become more image-led, but the next step is not more generic styling. The goal is to understand how leading biophilic, planting-system and spatial-design companies structure products, projects, technical proof and maintenance, then translate only the useful principles into Plantupia's own source material.

## Reference matrix

1. Green Fortune / Plantwire — product as a spatial idea, repeated project imagery before explanation, custom-made scope, maintenance integrated into the product story. Project pages link product ↔ built application. Useful principle: show the system in many spatial conditions before technical explanation.
2. Green Fortune / Projects — product concepts and projects live in one world. Useful principle: projects are not a separate portfolio appendix.
3. SIA — “one ecology / five practices”; design, delivery and long-term care sit together, while selected work remains visually dominant. Useful principle: practices should explain what sits behind the finished landscape.
4. Opiary — fabrication studio framing; custom objects/planters and projects coexist. Useful principle: vessels can be authored objects, not just SKU cards.
5. Greenery NYC — sector-led portfolio plus design / installation / maintenance. Useful principle: visitors can enter through context (office, hospitality, commercial) but still reach project proof quickly.
6. Leaflike — hospitality atmosphere first, method second. Useful principle: for hospitality, arrival/feeling can lead before service taxonomy.
7. Biotecture — deep project filtering by type, space, location and attributes. Useful principle: filters become useful only when archive depth is large enough; not needed as primary interaction for six studies.
8. SageGreenLife — named system/platform language plus real project proof. Useful principle: system naming is powerful only when Plantupia has evidence for a repeatable system; do not invent branded systems prematurely.
9. Greenmood — product/specification/download/sample language. Useful principle: technical data belongs close to a product/material family, not scattered through storytelling.
10. Garden on the Wall — project proof + material/specification evidence. Useful principle: separate design claims from measured/specification evidence.
11. Plant the Future — studio, custom work and shop live under one creative identity. Useful principle: commerce can feel like another expression of the studio rather than an unrelated ecommerce skin.
12. Ambius — case studies combine multiple images with concise project facts and service/solution labels. Useful principle: facts should anchor image sequences without turning them into dashboards.
13. Plant Solutions — Discovery → Design → Service. Useful principle: a short process can orient a buyer, but should not dominate the visual experience.

## Strong conclusions for Plantupia
- Project imagery should be the primary structural material.
- Technical diagrams appear only when a photograph/render cannot communicate the point.
- Case studies must not share one rigid template; the source material decides the interaction.
- Projects, systems/materials and care should connect to one another.
- Product/system naming should wait for evidence of repeatability. Current source safely supports: plants, custom vessels/planters, planting compositions, irrigation/care programme, maintenance.
- The Hospitality catalogue can seed a future Materials / Vessels / Planting Library, but not a fake product taxonomy.
- Project Archive is useful as index; direct project discovery should also exist from Spaces, Home and global navigation.
- Shop must visually inherit the studio/material language, not become a separate generic retail UI.
- Sustainability/technology claims need evidence. Prefer showing care, irrigation, specification, longevity and site-fit rather than broad unsupported impact claims.

## Visual grammar to test
1. PROJECT FIELD — irregular image rhythm, large moments, minimal labels.
2. SYSTEM / MATERIAL — object images, details, finishes and conditions grouped tightly with specification.
3. CONTINUITY — image of a space followed by installation/care/service evidence, not an abstract dashboard.
4. COMPARISON — when source offers options from one angle, use same-frame comparison/wall rather than carousels.
5. SEQUENCE — when source offers a spatial journey, scroll through chapters/areas with image-led transitions.

Reference research is directional only. Do not reproduce another company's layouts, copy, system names or proprietary visual identity.
